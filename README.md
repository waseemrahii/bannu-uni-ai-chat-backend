AI Chat System - Backend (Bannu University CS)

Features:
- Auth (admin / cr / student)
- Schedules (class & exam)
- Results (by roll no)
- Events (holidays, department events)
- General Info (guidelines, admissions, policies)
- Real-time chat with AI (Socket.IO)
- AI integration (Gemini) via utils/aiHelper.js

Run:
1. npm install
2. fill .env (MONGO_URI, JWT_SECRET, GEMINI_API_KEY, GEMINI_API_URL)
3. npm run dev
